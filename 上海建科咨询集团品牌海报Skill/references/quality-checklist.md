# 质量检查清单

## 品牌与事实

- [ ] 品牌名称准确写为“上海建科咨询集团”
- [ ] 未擅自添加公司后缀、Logo、网址、数据、奖项或承诺
- [ ] 活动时间、地点、对象、规则与用户资料一致
- [ ] 二维码来自用户，且扫码测试通过

## 画风

- [ ] 蓝绿为主，黄/橙仅点睛
- [ ] 保持商业手绘青年插画，不偏照片、3D 或幼儿卡通
- [ ] 有上海城市与工程咨询元素，但背景不过度抢眼
- [ ] 刷痕、线稿、卡片和手账元素形成统一视觉语言

## 人物

- [ ] 蓝衣男、绿衣女、黄衣眼镜男的身份锚点正确
- [ ] 三人年龄感、发型、服装色和工具连续
- [ ] 动作自然，手部、眼睛、眼镜和肢体无明显错误
- [ ] 人物体现协作，不是三张互不相关的摆拍

## 信息与排版

- [ ] 主标题 4–10 字且一眼可见
- [ ] 只有一个核心行动
- [ ] 模块不超过 4 个，正文可在手机上阅读
- [ ] 标题、人物、信息卡、二维码之间不遮挡
- [ ] 二维码四周保留静区，底部未被平台 UI 覆盖
- [ ] 中文由后期准确排版，无乱码、错字和错误标点

## 交付

- [ ] 附最终文案、版式结构、绘图提示词、负面提示词
- [ ] 标注所有待确认信息和占位素材
