# 人物角色档案

三位角色构成“上海建科青年创作协作组”。当前参考来自原海报裁切图，正式投入系列化生产前，建议基于此档案制作正面、侧面、背面和表情立绘。

## 角色 A：蓝衣青年

- 视觉位置：通常位于群像后上方。
- 外观：东亚青年男性，约 24–30 岁，黑色蓬松短发，无眼镜，开朗笑容。
- 服装：亮蓝色休闲衬衫外套，内搭白色圆领上衣。
- 工具与动作：手持黑色笔或触控笔，抬手讲解、指向创意或讨论方案。
- 能力标签：创意力、策划力、引导力。
- 锁定描述：`东亚青年男性，黑色蓬松短发，亮蓝色衬衫外套与白色内搭，阳光自信的笑容，手持黑色笔讲解创意，精致商业手绘漫画人物，深色清晰外轮廓，柔和赛璐璐上色`

## 角色 B：绿衣青年

- 视觉位置：通常位于群像中部，连接另外两人。
- 外观：东亚青年女性，约 23–29 岁，深棕色齐肩短发，轻薄刘海，无眼镜，专注微笑。
- 服装：绿色连帽卫衣，白色抽绳。
- 工具与动作：操作银灰色笔记本电脑，负责整理、编辑与协作。
- 能力标签：排版力、编辑力、协作力。
- 锁定描述：`东亚青年女性，深棕色齐肩短发与轻薄刘海，绿色连帽卫衣和白色抽绳，专注温和的笑容，双手操作银灰色笔记本电脑，精致商业手绘漫画人物，深色清晰外轮廓，柔和赛璐璐上色`

## 角色 C：黄衣青年

- 视觉位置：通常位于群像右下前景。
- 外观：东亚青年男性，约 23–29 岁，黑色整洁短发，黑色细框眼镜，专注微笑。
- 服装：明黄色连帽卫衣。
- 工具与动作：用触控笔在深色数位板/平板上绘图，桌面有工程图纸。
- 能力标签：执行力、设计力、传播力。
- 锁定描述：`东亚青年男性，黑色整洁短发，黑色细框眼镜，明黄色连帽卫衣，专注友善的笑容，手持触控笔在深色数位板上绘图，桌面铺有工程图纸，精致商业手绘漫画人物，深色清晰外轮廓，柔和赛璐璐上色`

## 群像关系

- A 在后方提出方向，B 在中间协同编辑，C 在前景落地执行。
- 三人朝向同一工作区或形成自然视线连接，体现共同创作而非各自摆拍。
- 身高和景深形成后高前低的三角构图。
- 可更换任务：审图、讨论项目、培训、公益、节日活动，但核心服装色和脸部特征保持稳定。

## 连续性规则

- 不交换三人的标志服装色。
- 不随意增加胡须、帽子、夸张首饰或成熟商务西装。
- 不把人物画成未成年人。
- 单次出图优先保留至少两项身份锚点：脸部/发型 + 服装色；工具作为第三锚点。
- 多张系列图使用相同参考图、相同锁定描述、相近随机种子和风格强度。
