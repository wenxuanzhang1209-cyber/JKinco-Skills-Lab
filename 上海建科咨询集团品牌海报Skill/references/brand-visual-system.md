# 品牌视觉系统

## 核心气质

关键词：青年、专业、协作、工程咨询、城市建设、上海、向上、清爽、可信、行动感。

画面采用“精致商业手绘插画 + 轻漫画人物 + 建筑线稿信息图”的混合风格。人物亲和但不幼态，工程背景专业但不沉重，信息丰富但通过卡片和留白保持秩序。

## 色彩

从参考图提取的近似屏幕色，仅用于复现该海报视觉，不等同于企业正式 VI：

- 品牌深蓝：`#07339F` / `#1F52A4`
- 活力亮蓝：`#1E6CD1`
- 青年绿：`#21744B`
- 辅助浅蓝：`#97AFD8` / `#B3CAE3`
- 背景雾白：`#EBF0F5`
- 行动黄：`#EBA621`
- 橙色点睛：建议 `#F28A2E`
- 正文墨色：建议 `#17233C`

蓝色承担品牌与专业，绿色承担成长与协作，黄色/橙色只用于行动与重点。单张海报中蓝绿合计应占主导，暖色不宜大面积铺陈。

## 插画语言

- 使用清晰深色外轮廓、柔和赛璐璐上色、轻水彩纸感和局部高光。
- 人物面部采用东亚青年特征、自然笑容、大而不过分夸张的眼睛。
- 背景以淡蓝建筑透视线稿与低饱和色块表现，不与人物争抢。
- 前景可放工程图纸、建筑模型、书册、电脑、平板和文具，体现咨询与建设行业。
- 用手绘刷痕、星形、纸飞机、扩音器、虚线路径、对话气泡增加传播感。
- 边缘可用蓝色笔刷与城市线稿收边，形成“海报手账 + 城市蓝图”质感。

## 上海与行业识别

可选元素：

- 东方明珠、上海中心等上海天际线剪影。
- 斜拉桥、城市道路、建筑工地与塔吊。
- 工程图纸、BIM/建筑模型、城市更新界面、咨询报告书。
- 智慧城市、绿色建筑、数字化、工程管理等抽象图标。

地标只作背景识别，不堆成旅游海报。避免错误比例、混入明显外地地标或生成不存在的企业 Logo。

## 字体与文字效果

未提供正式品牌字体时：

- 主标题：粗黑体或手写刷体，略微倾斜，边缘带干刷纹理。
- 模块标题：粗黑体，白字置于蓝/绿刷痕标题条。
- 正文：清晰现代黑体，行距宽松。
- 口号：手写感中文字体或规范楷体风格。

生成模型不应承担大段中文正文。将标题、说明、日期与 CTA 后期排入，保证准确。

## 禁止偏移

- 不做照片写实、3D 塑料玩具、欧美超级英雄、幼儿绘本或复古民国风。
- 不做纯互联网霓虹赛博朋克，也不把工程感变成机械重工业压迫感。
- 不使用大面积粉紫渐变替代蓝绿体系。
- 不让背景建筑遮挡标题、人物脸部或二维码。
- 不复制其他品牌 Logo、吉祥物或受保护角色。
