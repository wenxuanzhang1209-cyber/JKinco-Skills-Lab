# 上海建科咨询集团品牌海报

## 执行原则

1. 始终使用品牌名“上海建科咨询集团”。除非用户明确提供，不擅自添加“有限公司”、Logo、网址、地址、电话或口号。
2. 先读取 [brand-visual-system.md](references/brand-visual-system.md)、[character-bible.md](references/character-bible.md) 和 [copy-layout-system.md](references/copy-layout-system.md)。
3. 把 [reference-poster.jpg](assets/reference-poster.jpg) 作为最高优先级视觉依据；需要锁定人物时同时使用 [character-group-reference.jpg](assets/character-group-reference.jpg)。
4. 保留“青年活力 + 工程专业 + 上海城市识别 + 信息清晰”的组合，不只模仿蓝绿色。
5. 采用“两阶段成图”：先生成无大段文字的插画底图，再在设计工具中排中文。只有模型中文排版可靠时才尝试一体生成。
6. 不照搬参考海报中的具体活动信息、二维码或报名内容；只复用视觉语法、人物设定和文案方法。

## 工作流

### 1. 补齐简报

从用户输入中提取：主题、用途、受众、核心行动、时间地点、必须出现的信息、二维码/Logo、尺寸、发布平台。信息不足时使用 [brief-template.md](references/brief-template.md) 形成“待确认项”，不得虚构事实。

### 2. 确定内容层级

按以下顺序组织：

1. 品牌眉题：上海建科咨询集团 + 栏目/人群/活动类型
2. 4–10 字主标题：行动词或主题词优先
3. 两行副标：第一行讲价值，第二行讲对象或行动
4. 2–4 个信息模块：对象、内容、亮点、福利、流程、时间地点
5. 一句收束口号
6. 明确 CTA：扫码报名、关注了解、加入活动等

正文较多时，宁可删减或拆成系列海报，不把字体缩到难以阅读。

### 3. 选择构图

默认使用 2:3 竖版：

- 顶部约 30%：品牌眉题、超大主标题、上海天际线。
- 中部约 45%：左侧白色信息卡，右侧三人青年协作群像。
- 底部约 25%：福利/亮点横卡、口号和二维码/CTA。

主题不适合三人群像时可减少人物，但保持角色设定与同一插画宇宙。详细网格见 [copy-layout-system.md](references/copy-layout-system.md)。

### 4. 生成交付包

每次至少输出以下内容：

- `海报文案`：可直接排版的最终中文。
- `版式结构`：按顶部/中部/底部标注内容与占比。
- `主绘图提示词`：描述画面，不塞入长段正文。
- `负面提示词`：排除写实摄影、幼儿卡通、杂乱信息、错误地标、异常手部、伪 Logo、乱码文字等。
- `后期排版清单`：字体层级、颜色、二维码留白、Logo 与版权素材位置。
- `质检报告`：逐项对照 [quality-checklist.md](references/quality-checklist.md)。

写 `主绘图提示词` 和 `负面提示词` 前先读取 [prompt-templates.md](references/prompt-templates.md)，按里面的结构填，不要临场自拟句式——换一次句式，出图风格就漂一次。

需要扣子等平台可直接粘贴的系统提示词时，读取 [coze-system-prompt.md](references/coze-system-prompt.md)。

## 人物连续性

- 固定三位青年角色的发型、服装色、眼镜、工具和能力标签。
- 允许改变动作、景别与场景，不随意改变年龄、性别呈现和核心外观。
- 使用支持参考图的平台时，附带人物群像参考图，并提高角色/风格参考权重。
- 不支持参考图的平台时，逐字复用 [character-bible.md](references/character-bible.md) 中的“锁定描述”。
- 若用户提供后续确认过的人物立绘，以新立绘替代当前裁切参考，并更新角色档案。

## 文案约束

- 使用短句、动词和对仗，语气积极、专业、年轻，不网络低俗化。
- 主标题强调行动或主题；副标强调专业价值与青年成长。
- 信息卡标题保持 2–6 字，说明保持 12–32 字。
- 可采用“用 X 呈现 Y / 用 X 讲述 Y”“排出精彩，编出价值”这类双句式，但避免每张海报机械复刻。
- 企业事实、项目数据、荣誉、日期、报名规则必须来自用户提供或经核实的资料。

## 交付与适配

- 默认输出 1024×1536 或同等 2:3 竖版。
- 朋友圈/公众号长图可沿用 2:3；小红书优先 3:4；视频封面优先 9:16；横版屏幕另做 16:9 重排，不直接裁掉人物与信息卡。
- 导出前检查安全边距、二维码可扫性、最小字号和品牌名。
- 若只生成提示词，也要附上版式与中文文案，确保换平台后仍可复现。
