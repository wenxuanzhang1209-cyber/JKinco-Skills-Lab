# JKinco Skills Lab

> **English overview** · Reusable AI skills that turn repetitive brand-design work into callable workflows: structured drafts, image/video prompts, and quality-check results.

一套可复用的 AI 技能（Skills）集合，把重复的品牌设计工作固化为可调用的工作流：输入需求，输出结构稿、提示词、质检结果。

## 包含的技能

| 技能 | 名称 | 用途 |
| --- | --- | --- |
| `shanghai-jianke-poster` | 上海建科咨询集团品牌海报 | 生成统一品牌风格的中文宣传海报 |
| `xiaozhi-product-video` | 上海建科小智产品视频 | 以品牌角色“小智”为主角的产品宣传视频 |
| `入职小百科` | 小智入职大冒险 - 入职小百科 | 新员工入职知识内容包 |

## 使用方式

将对应技能目录放入你的 Codex skills 目录（或按所用 Agent 平台的 skills 规范导入），在对话中按技能描述触发即可。

## 目录结构

```
JKinco-Skills-Lab/
├── 上海建科咨询集团品牌海报Skill/
├── 上海建科小智产品视频Skill/
└── 小智入职大冒险-入职小百科正式版 2/
```
