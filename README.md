## 小智入职大冒险

- 六大站点对应手册六个章节，共 25 道情景题，全部通关后解锁 4 道终极综合题。
- 支持进度存档续玩、键盘操作、错题本与错题重练、知识卡搜索。
- `python3 build.py` 可打包出零外部依赖的单文件 HTML，便于内网部署或直接转发。
- 对外发布前请按 `脱敏说明.md` 执行关键词扫描：不得出现账号密码、内网地址、
  办公与个人电话、个人邮箱、人员名单及内部制度文号。
