# 公文写作系统

## 语气

使用正式、克制、可执行的书面语。避免广告化、口语化、情绪化和空泛拔高。

优先：

- 为进一步……
- 按照……要求……
- 根据……规定……
- 经研究，决定……
- 现将有关事项通知如下：
- 请各部门……
- 逾期不予受理。
- 其他有关事项另行通知。
- 特此通知。

避免：

- 重磅来袭、火热报名、机会难得、赶快参加
- 赋能升级、全面领先等缺乏具体含义的堆叠词
- “务必必须”“大概预计”等逻辑冲突
- 未经依据的“显著提升”“确保零风险”“行业第一”

## 导语

导语控制在 1–2 段，依次回答：

1. 为什么发文：背景、计划、制度依据。
2. 要解决什么：目的。
3. 做什么决定：组织开展、调整、公布、申报。
4. 如何引出正文：现将有关事项通知如下。

## 主体组织

- 申报类：任务/范围 → 申报条件 → 材料 → 程序 → 时间 → 要求。
- 培训类：目的 → 时间 → 地点 → 对象条件 → 日程 → 报名。
- 制度调整类：目的依据 → 调整内容/表格 → 适用范围 → 生效和废止 → 特此通知。
- 评选结果类：评选依据和程序 → 结果名单 → 特此通知。

## 句法

- 一句表达一个主要动作；长句超过约 45 字时优先拆分。
- 对同级事项使用平行句式。
- 条件、责任主体、动作、截止时间和提交对象要完整。
- 避免主语缺失造成责任不清。

示例：

```text
请各业务机构于【日期】前，将经部门审核的【材料名称】提交至【部门/系统】。
```

不要写成：

```text
请及时做好相关材料报送工作。
```

## 数字、日期和名称

- 年份写四位数；日期写明月日，必要时附星期并核对。
- 时间范围统一使用连接号或“至”，同一文件不混用。
- 金额必须写清“以下、以上、至、含/不含”的边界。
- 企业、部门、制度、系统和附件名称首次出现使用全称。
- 引用制度时核对名称、编号、版本和条款。
- 名单按审批材料原文录入，姓名和部门逐项双人复核。

## 标点

- 中文正文使用全角标点。
- 书名、制度、表单名称使用书名号。
- 层级编号后标点遵循同一模板。
- 标题末尾不加句号。
- “附件：”使用全角冒号。

## 保密和合规

- 对资金审批、人员名单、邮箱、联系方式和内部系统路径进行权限确认。
- 不把内部材料自动改写为对外发布稿。
- 党委文件、印章、文号必须经过授权流程。
- 不生成虚假印章、签名、批示或审批意见。
