# 公文质量检查清单

## 发文身份

- [ ] 发文主体全称准确
- [ ] 普通公司、承办部门、党委主体未混用
- [ ] 文种和红头类型正确
- [ ] 文号、签发日期、承办部门已确认

## 事实

- [ ] 制度名称、编号、版本、条款准确
- [ ] 日期与星期对应
- [ ] 时间、地点、对象、条件、提交方式完整
- [ ] 金额区间无遗漏和重叠
- [ ] 名单、部门、邮箱、联系人逐项核对
- [ ] 附件名称与正文一致

## 语言

- [ ] 标题准确概括事项
- [ ] 导语包含依据/目的/行动
- [ ] 责任主体和动作明确
- [ ] 同级条目句法平行
- [ ] 无宣传化、口语化或绝对化表达
- [ ] 无错别字、重复词和标点混用

## 版式

- [ ] A4 纵向，页边距和版心统一
- [ ] 企业页眉或党委红头使用正确
- [ ] 标题居中，主送机关顶格
- [ ] 正文首行缩进 2 字，层级编号统一
- [ ] 页码连续
- [ ] 表格不越界、不截字，跨页重复表头
- [ ] 落款、日期、印章预留和版记位置正确
- [ ] 无宣传插画、装饰照片和无关图形

## 发布前

- [ ] 所有 `【待确认】` 已清除或明确保留
- [ ] DOCX 已渲染并逐页检查
- [ ] PDF 与 DOCX 页数、内容一致
- [ ] 印章、签名和审批意见来自正式流程，非 AI 生成
- [ ] 内部敏感文件已确认发布范围
