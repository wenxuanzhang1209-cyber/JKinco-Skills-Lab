# 产品视频文案与分镜

## 简报模板

```text
【企业】上海建科咨询有限公司
【产品名称】
【目标受众】
【核心痛点】
【核心卖点 1–3】
【使用场景】
【希望观众采取的行动】
【时长】15 / 30 / 60 / 90 秒
【比例】16:9 / 9:16 / 1:1
【发布平台】
【必须出现的信息】
【禁止出现的信息】
【Logo、产品 UI、截图、二维码】
【待确认项】
```

## 30 秒默认结构

| 时间 | 功能 | 建议画面 |
|---|---|---|
| 0–3 秒 | 抓住注意 | 小智出场 + 用户痛点 |
| 3–8 秒 | 提出产品 | 小智指向产品名称/界面 |
| 8–20 秒 | 展示价值 | 3 个卖点，每个约 4 秒 |
| 20–26 秒 | 场景证明 | 工程/办公室/数字化场景 |
| 26–30 秒 | CTA | 小智点赞或挥手 + 行动号召 |

## 文案语气

- 小智使用第一人称，语气清晰、亲切、专业。
- 先说用户问题，再说产品如何帮助，不堆技术术语。
- 每句话尽量 8–20 字，方便口播与字幕。
- 产品能力、节省比例、覆盖范围、客户案例必须来自用户材料。
- 不使用“绝对安全”“百分百准确”“行业第一”等未经证实表达。

## 镜头表字段

每个镜头写明：

1. 镜头编号与时长
2. 旁白
3. 屏幕文字
4. 景别和机位
5. 小智动作与表情
6. 场景和产品 UI
7. 相机运动
8. 音乐/音效
9. 角色参考图
10. 首帧提示词与视频提示词

## 常用动作库

- 正面挥手开场
- 竖起大拇指确认
- 侧身指向屏幕
- 手持平板查看信息
- 低头查看工程图纸
- 走两步后停下讲解
- 点头回应
- 转向建筑或数字孪生模型

一个镜头只选一个主要动作。
