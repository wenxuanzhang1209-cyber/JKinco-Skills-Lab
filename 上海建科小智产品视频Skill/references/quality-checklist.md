# 小智视频质量检查

## 企业与内容

- [ ] 企业名称为“上海建科咨询有限公司”
- [ ] 产品名称、数据、案例和承诺来自用户资料
- [ ] 字幕、Logo、产品 UI 和二维码使用正式素材后期合成
- [ ] 无参考图自带水印

## 角色身份

- [ ] 同一圆润 3D Q 版男性工程师
- [ ] 棕色短发、深棕眉、超大棕色圆眼
- [ ] 圆润脸、暖肤色、圆耳和小圆鼻一致
- [ ] 白色安全帽结构一致
- [ ] 亮蓝反光背心和银灰反光条结构一致
- [ ] 深蓝衬衫、长裤和黑色工作鞋一致
- [ ] 头身比与四肢比例无漂移
- [ ] 帽前、左胸、后背标识位置正确

## 跨镜头

- [ ] 相邻镜头脸部和眼睛大小一致
- [ ] 服装蓝色、肤色和棕发色一致
- [ ] 镜头切换不突然增减配件
- [ ] 背面镜头符合背面参考图
- [ ] 动作无多余手指、肢体穿模或面部融化
- [ ] 嘴型与配音自然，不破坏脸型

## 视频与安全

- [ ] 一个镜头只有一个主要动作
- [ ] 施工场景符合基本安全常识
- [ ] 相机运动平稳，主体未被裁切
- [ ] 产品 UI 可读，字幕在安全区
- [ ] 音乐不盖过旁白
- [ ] CTA 清晰且事实准确

任何角色身份项失败，该镜头不得进入正式成片。
