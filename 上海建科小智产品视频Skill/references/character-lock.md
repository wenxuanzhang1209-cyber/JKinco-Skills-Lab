# 小智角色锁定档案

## 身份

- 名称：小智
- 所属：上海建科咨询有限公司
- 定位：亲切、可靠、聪明、积极的工程咨询品牌角色与产品讲解员
- 形象语言：高品质 3D Q 版卡通，圆润、干净、可信，不幼稚

## 不可变外观

### 头部与面部

- 头身比约 1:2.6–1:3，头部明显大于身体。
- 圆润偏椭圆脸，浅暖肤色，柔和粉色面颊。
- 棕色短发，从安全帽下露出顺滑侧发和后脑圆弧。
- 粗而整齐的深棕眉毛。
- 超大圆形棕色眼睛，深色瞳孔，白色高光环；眼白清楚。
- 小巧圆鼻，耳朵略大且圆。
- 常态为友好微笑，嘴型简洁；允许眨眼、闭眼笑、惊喜和专注表情。

### 安全帽

- 白色标准工程安全帽，圆润 3D 材质，前沿清晰，顶部有纵向加强筋。
- 正面标识区域固定居中。Logo 和文字优先后期贴图，不让模型重画。
- 不改变为黄色、蓝色、棒球帽、头盔或无帽状态。

### 服装

- 内层：深海军蓝长袖工装衬衫，翻领。
- 外层：亮蓝色高可视反光背心，前开襟。
- 反光条：浅银灰色；肩部纵向条 + 腰部两条横向条。
- 下装：同色深海军蓝直筒工装长裤。
- 鞋：黑色圆头工作鞋，低跟。
- 背心左胸和背部为品牌标识区域。标识必须使用正式素材后期合成。

### 身体比例

- 四肢短而圆润，手掌与手指偏大，适合清晰手势。
- 躯干短，腿部约占全身一半。
- 双脚稳固，站姿积极。


## 品牌标识规则

- 参考图中的帽前、左胸、后背是标识位置基准。
- 生成阶段可保留清晰的空白标识贴图区。
- 后期使用企业确认的透明 PNG/SVG 贴图。
- 未提供正式 Logo 文件时，只能使用参考图作为视觉指引，不得自行重绘、猜测或声称达到印刷级准确。

## 允许变化

- 动作：挥手、点赞、指引、讲解、操作平板、查看图纸、巡视、展示产品界面。
- 表情：微笑、专注、惊喜、点头、眨眼。
- 场景：施工现场、智慧工地、办公室、会议室、城市更新、数字孪生空间、产品 UI 环境。
- 镜头：全身、中景、近景、过肩、跟拍；背面镜头必须参考背面图。
