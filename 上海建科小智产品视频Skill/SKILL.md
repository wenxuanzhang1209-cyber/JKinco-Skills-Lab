# 上海建科小智产品视频

## 最高优先级

1. 始终使用企业名称“上海建科咨询有限公司”。只有用户明确要求简称时，才在画面或旁白中使用简称。
2. 把 [xiaozhi-turnaround-master.png](assets/xiaozhi-turnaround-master.png) 作为角色造型最高依据，把 [xiaozhi-cinematic-master.png](assets/xiaozhi-cinematic-master.png) 作为电影感和工程场景依据。
3. 生成每一个含小智的镜头时必须附带角色参考图。平台不支持角色参考、首尾帧、图生视频或角色模型时，不得承诺“完全一致”；先输出关键帧方案或建议训练专用角色 LoRA/模型。
4. 不根据文字重新设计小智，不替换安全帽、服装、脸型、眼睛、发型、配色或标识位置。
5. 标识优先使用用户提供的原始图形素材后期贴合，不让生成模型重新拼写企业中文或重画 Logo。
6. 原始设定图右下角的生成水印不是角色组成部分，成片中不得复现。

## 执行流程

### 1. 整理需求

提取产品名称、目标受众、核心痛点、3 个以内核心卖点、行动号召、时长、比例、平台、配音语气、必须出现的画面和合规限制。缺失事实标记为“待确认”，不虚构产品能力、客户、数据或项目案例。

### 2. 选择一致性等级

- **A级：严格一致**。使用原始角色图作首帧/角色参考，逐镜头图生视频；固定角色模型、种子、参考权重和色彩。默认采用。
- **B级：近似一致**。平台仅支持一张参考图时，使用正面参考[xiaozhi-front-reference.png](assets/xiaozhi-front-reference.png)，限制动作和镜头旋转；需要背面镜头时用 [xiaozhi-back-reference.png](assets/xiaozhi-back-reference.png)。
- **C级：文字近似**。平台只支持文生视频时，只能生成风格近似的小智，不得标记为品牌正式成片。

用户要求“必定一致”时只能采用 A 级。若平台能力不满足，停止直接生成，转为关键帧、三视图补全或角色模型训练方案。

### 3. 先锁定静态关键帧

先为所有镜头生成静态分镜关键帧，逐张通过角色检查后再动画化。不要一次性文生完整长视频。每个视频片段建议 3–6 秒，复杂动作拆成多个镜头。

### 4. 动画化

优先采用“已确认关键帧 → 图生视频”。限制镜头内变化，只改变动作、表情、相机和环境；不得让角色在运动中换装、变脸或丢失 Logo。

### 5. 后期合成

把准确 Logo、企业名称、产品 UI、字幕、数据和 CTA 后期叠加。避免生成模型直接绘制长中文、界面小字和二维码。

### 6. 交付

每次至少输出：

- 视频创意概述
- 时长与平台规格
- 旁白和屏幕文案
- 镜头表：时间、景别、动作、场景、相机、声音
- 每镜头首帧提示词
- 每镜头图生视频提示词
- 通用负面提示词
- 角色参考图使用说明
- 后期素材清单
- 一致性质检报告

## 不可妥协规则

- 小智必须为同一个 3D Q 版东亚男性工程师形象。
- 不改变白色安全帽、棕色短发、棕色大眼、圆润脸型、蓝色反光背心、深蓝工装和黑鞋。
- 不添加胡须、眼镜、帽饰、披风、武器、潮牌服装或成人写实五官。
- 不把角色变成真人、二维平面漫画、毛绒玩具、机器人或动物。
- 不在施工现场表现违反安全规范的危险动作；必要时补充现场要求的防护用品，但不得改掉核心制服。
- 不让小智代言未经用户确认的产品效果或承诺。
